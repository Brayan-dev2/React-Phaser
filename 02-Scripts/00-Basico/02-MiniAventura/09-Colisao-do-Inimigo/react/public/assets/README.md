# Assets desta aula

Arte pixel art criada especialmente para a trilha **Meu Primeiro Jogo**
(licença livre, igual à do repositório: MIT). Você pode usar, estudar e
modificar à vontade.

| Arquivo | O que é |
|---|---|
| `ceu.png` | Plano de fundo (céu com sol e nuvens) 1280x720 |
| `chao.png` | Pedaço do chão 128x128 (usado com tileSprite, repete sem emenda) |
| `plataforma.png` | Plataforma 192x64 (repete na horizontal) |
| `nuvens.png` | Faixa de nuvens 1280x300 (repetição perfeita) |
| `montanhas.png` | Montanhas 1280x320 (repetição perfeita) |
| `montanhas-claras.png` | Colinas distantes 1280x240 |
| `heroi-parado.png` | Herói parado: 2 quadros de 128x128 |
| `heroi-correndo.png` | Herói correndo: 4 quadros de 128x128 |
| `heroi-pulando.png` | Herói pulando: 1 quadro de 128x128 |
| `heroi-dano.png` | Herói levando dano: 1 quadro de 128x128 |
| `gosma-andando.png` | Gosma (inimigo): 4 quadros de 104x80 |
| `gosma-derrotada.png` | Gosma derrotada: 2 quadros de 104x80 |
| `moeda.png` | Moeda girando: 4 quadros de 64x64 |
| `estrela.png` | Estrela 64x64 |
| `coracao.png` | Coração (vidas no HUD) 64x64 |

> Dica: cada personagem foi desenhado em pixels grandes e depois ampliado,
> com contorno escuro (estilo pixel art).
> Para trocar a arte, mantenha o mesmo tamanho de quadro.
